# ProtonectMAC branding

This folder keeps repository-facing branding separate from source and build assets.

- `protonectmac-logo.svg` — horizontal README/website wordmark.
- `protonectmac-mark.svg` — square icon suitable for avatars, badges, or a social-preview composition.

The mark is intentionally generic: it references a depth sensor and projected depth waves without using Apple, Microsoft, Xbox, or Kinect trademark artwork.
